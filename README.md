# Smart_Diet_Planner

Plan your personalized diet plans with our Smart Diet Planner
🚀 Features

## Personalized Meal Planning ##
- Takes user inputs like age, weight, goals (e.g., weight loss, muscle gain)
- Suggests balanced diets using AI-driven recommendations
- Adjusts meals based on user feedback and updates

## Recipe Generator ##
- Users can type any food name and get a recipe
- Uses machine learning to suggest healthier alternatives

## Nutrition from Images (Visual Analysis) ##
- Users can upload an image of food
- App detects food item and estimates nutritional content

##  AI & Machine Learning ##
- Uses **XGBoost** for intelligent recommendation
- Integrates **image recognition and sentiment models**

## API Integration ##
- Pulls data from nutrition APIs to enrich meal details, such as Groq, Meta llama,etc.
- Offers smart automation for food tracking
